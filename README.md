# Multitasking — Памятка (Updated)

---

## 🚀 Быстрый старт
1. Запустите бота.
2. Выполните команду `!роль_админ @роль` — это назначит главного управляющего.
3. Используйте команду `/панель_настройки` для интерактивной конфигурации всех функций бота.

---

## ⚙️ Интерактивные настройки
Вместо ввода множества команд, используйте `/панель_настройки`. Она позволяет управлять:
- **Заявками:** Менеджеры, пинг-роли, логи и доступ.
- **Ролями:** Настройка ролей МП, ВЗП, Реаки и Магазина.
- **Варнами:** Привязка ролей к уровням предупреждений (1/3, 2/3,  la3/3).
- **Логами:** Каналы для заявок, магазина, общака и фидбека.
- **Сборами:** Доступ к командам `!vzp`, `!mp`, `!list`.
- **Войсом:** Начисление валюты 💎 за время в голосовых каналах.
- **Контентом:** Тексты и фото для Личного кабинета, Общака и Feedback.

---

## 📋 Основной функционал

### Сборы (Events)
- Команды: `/vzp`, `/mp`, `/reaki` (и их префикс-версии `!vzp`, `!mp`, `!list`).
- Особенности: Авто-теги ролей, создание треда со списком, поддержка резерва и времени.
- Управление: `!замена <id_кого> <id_на_кого>` (в треде), кнопки "Закрыть/Открыть список".

### Тикет-система (Заявки)
- Подача через кнопку $\rightarrow$ Форма $\rightarrow$ Создание канала.
- Обработка: Одобрение/Отклонение с уведомлением в ЛС.
- **Новинка:** Кнопка "Пригласить на обзвон" создает голосовой канал и отправляет инвайт в ЛС участнику.

### Экономика и Магазин
- Валюта: Алмазы 💎 (активность) и Фишки 🎰 (рулетка).
- Магазин: Автоматическая выдача ролей или снятие варнов за баллы.
- Команды: `!баланс`, `!обмен`, `!дать`, `!снять`.

### Приватные комнаты
- Создание канала по триггеру $\rightarrow$ Личная панель управления (слоты, доступ, переименование, передача прав).

### Дополнительно
- **АФК и Инактив:** Панели для отслеживания отсутствующих.
- **Общак:** Система пополнения баланса организации с логами.
- **Личный кабинет:** Эфемеральный профиль с балансом, варнами и статистикой.
- **Feedback:** Система сбора предложений с тредами для обсуждения.
- **Контракты:** Система взятия заданий с отслеживанием времени и участников.
